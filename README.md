# 📖 About Project

IPL Cricket Analytics Dashboard is a Full Stack Web Application built using **React.js**, **FastAPI**, **Python**, **Pandas**, and **Machine Learning**.

This project allows users to analyze IPL data, compare teams, search players, visualize statistics, and predict match winners using an ML model.

The project is designed as a professional portfolio project and demonstrates both frontend and backend development with data analytics.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/thenameisvirus/IPL-Cricket_Dashboard.git
```

---

## Frontend

```bash
cd frontend
npm install
npm run dev
```

---

## Backend

```bash
cd backend

pip install -r requirment.txt

uvicorn main:app --reload
```
